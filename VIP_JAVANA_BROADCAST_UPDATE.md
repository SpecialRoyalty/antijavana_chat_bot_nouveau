# Broadcast VIP JAVANA

Ajout du troisième broadcast VIP dans le panel admin.

- `📦 Broadcast Pass Total` : accès Total actuellement actifs.
- `🎟 Broadcast Pass soirée` : historique soirée hors utilisateurs ayant un Total actif.
- `💎 Broadcast VIP JAVANA` : accès JAVANA actuellement actifs.

Formats acceptés : texte, photo, photo + légende.
Le compte-rendu final affiche destinataires, envoyés, blocages et erreurs.
